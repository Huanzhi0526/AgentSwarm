## 一、软件定位与两种协作路线

**AgentSwarm** 不是单向聊天机器人，而是一个在本地运行的 **“群聊式多 AI 协同看板”**。它解决三个痛点：
- 不用同时切好几个黑框命令行窗口看不同 AI 干活；
- 不用人工复制粘贴成果给另一个 AI 评审或继续开发；
- AI 改文件前自动拍一份备份照片，不满意时可以逐文件对比前后差异并随时安全撤回。

在实际使用中，你有 **两条协作路线**：
1. **看板直驱模式**：在 AgentSwarm 界面里新建看板、分配好各个成员使用的引擎（比如 Antigravity、CodeX、CodeBuddy、Claude Code），直接在网页/桌面窗发送需求。软件会自动在后台调度本机安装好的 CLI 完成拆解、执行、汇总。
2. **桌面端 MCP 主管模式**：平时习惯在 Antigravity、CodeX、CodeBuddy 或 Claude Code 客户端主对话框里聊天的人，可以通过弹窗一键接入 AgentSwarm MCP，让桌面端的主对话担任「团队主管」去调度团队其他成员，同时在 AgentSwarm 看板里实时看进度、留插话、管备份。

> **重要前提**：AgentSwarm 本身是免费开源的本地协调软件，不包含大模型账号或云端额度。运行「内置离线导览」无需任何 AI 账号；运行真实任务时，至少需要在本机安装并登录一款受支持的 AI CLI 或桌面客户端。

## 二、安装与首次打开（含 SmartScreen 与托盘说明）

### 1. 下载与校验
- 前往 [Releases 页面](https://github.com/Huanzhi0526/AgentSwarm/releases/latest) 下载 **`AgentSwarm_<版本>_x64-setup.exe`**（普通用户推荐，简体中文向导、安装到当前用户目录、免管理员权限）。
- 如果需要企业部署或静默 MSI 包，可选择 `.msi` 文件（注意目前标记为 `en-US` 英文界面）。
- 安装包目前已包含完整 **Node.js 24 运行时**与前端服务产物，无需自己装 Node。

### 2. 处理 Windows 未签名安全提示
由于当前开源版本尚未购买商业代码签名证书（文件签名状态显示为 `NotSigned`），首次打开安装程序时：
1. 如看到「Windows 已保护你的电脑」蓝色弹窗，先确认文件来自官方 [Releases 页面](https://github.com/Huanzhi0526/AgentSwarm/releases/latest)，并在 PowerShell 核对 SHA-256 与页面一致：
   ```powershell
   Get-FileHash .\AgentSwarm_1.4.1_x64-setup.exe -Algorithm SHA256
   ```
2. 点击弹窗里的 **「更多信息」→「仍要运行」** 即可正常安装。

### 3. 系统托盘、关闭与彻底退出
- 桌面端启动后会在后台开启本地服务（默认端口 `25880`，无黑框闪窗）。
- 点击窗口右上角 `X` 时，程序默认**隐藏到 Windows 右下角系统托盘**继续保活，方便在浏览器或手机端访问。
- 如需 **彻底退出程序并关闭后台服务**，请右键点击右下角托盘里的 AgentSwarm 图标，选择 **「退出程序」**；也可以右键点击 **「在浏览器中打开」** 在默认浏览器访问全屏看板。

## 三、体验离线导览：认识三栏界面

第一次打开新数据库时，软件会自动展示 **「快速上手：多智能体协同导览」**：
- **左栏**：上方是项目会话列表（可建看板、点进「桌面端 MCP 接入」），下方是打勾任务进度清单，最底部显示当前软件版本号（`v1.4.1`）与实际数据存放位置。
- **中栏**：上方有导览提示卡和顶栏开关，中间是团队群聊时间线（每个成员的发言、团队分工卡、文件交付卡片一目了然），底部是多行输入框（支持 `@成员`、引用项目文件、常用指令模板、手动备份点和调整当前成员思考强度）。
- **右栏**：可在 **「团队与模型」**（随时调整成员引擎/模型/思考强度、新增/改名/切换主管、打开命令行会话）与 **「改动与备份」**（按时间查看自动或手动备份记录）之间切换。

## 四、建立你的第一个真实协同看板

点击左上角 **`+ 新建看板`**（或导览卡上的「创建我的第一个真实看板」），按照页面编号 1 → 2 → 3 进行：

1. **选择项目文件夹**：
   - 如果是首次试用且不想影响现有代码，可以直接点击右上角的 **「在「文档」新建练习文件夹」**，一键在你的「文档」下建好 `AgentSwarm-Demo` 空文件夹。
   - 也可以点击 **「选择文件夹」**，浏览到你的真实项目目录。为防误操作，软件会自动阻止选择磁盘根目录（如 `C:\`、`D:\`）、Windows 系统目录及 AgentSwarm 自身安装/数据目录。
2. **填写看板名称与检查主管就绪状态**：
   - 模板旁会明确告诉你当前主管工具是 **「已就绪」** 还是 **「未安装」**。
   - 如需调整成员数量、分工规则或换用别的 CLI，可展开「进阶：调整成员、模型与分工规则」。若暂时将某成员职责留空，主管会在开工第一轮结合全局分工偏好与模型特长自动分配职责。
3. **填好首条任务指令并创建**：
   - **安全草稿保护**：如果创建时所选的主管引擎本机尚未安装，你可以照样先建出看板——你写好的首条指令**不会白白发出去报错丢掉**，而是安全保留在新看板底部的输入框草稿里，等你把主管切换为可用引擎后再一键发出。

### 关于三种引擎状态提示
发送消息给某个成员后，若未能成功执行，群聊与提示条会区分三种常见情况：
- **引擎未安装**：本机没有找到该 CLI 可执行文件，点击提示条里的 **「切换至 XXX」** 或去右栏更换成员引擎即可重发。
- **需登录 / 配置密钥**：CLI 程序本身已装好，但未登录账号或缺少 API Key；请按提示在终端先完成登录，再点击失败消息下方的 **「重新编辑发送原消息」** 一键重试。
- **调用执行失败**：超时、网络中断或模型异常导致退出；若失败前成员已改动了一半文件，系统仍会自动留存 `failed_turn` 保护备份，方便你查看或撤回。

## 五、查看交付文件、对比修改与安全撤回

成员汇报任务并在项目目录修改或生成了文件时，消息气泡下方会出现文件卡与安全操作条：

1. **预览 / 打开**：点文件行 **「预览」** 可在软件内直接渲染 Markdown、代码、图片、PDF 或沙盒网页（隔离宿主机权限）；在本机操作时点 **「打开」** 可直接用电脑默认关联程序打开，不弹黑框。
2. **对比改动**：打开分栏视图，左侧显示 **修改前**，右侧显示 **修改后**。
3. **三向冲突保护（关键安全机制）**：
   - 当你想点 **「一键撤回」** 回到AI改动前的版本，而你自己在AI交付**之后**又手动修改过这个文件时，系统会立即拦住并发出冲突提示，展示磁盘最新内容与撤回目标的对比，给你两种选择：
     - **「保留较新修改（仅撤回无冲突文件）」**：绝对不覆写你的手工新编辑！执行完成后页面顶栏与成果卡会明确列出 **「已撤回还原 X 个文件，保留较新修改 Y 个文件」**，不会误导状态。
     - **「先自动备份当前内容再覆盖还原」**：系统先帮你给当前磁盘上的较新修改拍一份 `pre_overwrite_backup` 保护快照，然后再安全还原旧版，窗口内会直接给出 **「查看保护快照」** 快捷按钮，以后想反悔也能随时从保护快照还原回来。
4. **手动备份点**：随时可以点击输入框下方 **「保存备份」**（或右栏「改动与备份」的保存备份点），为当前全项目保存一份带全量清单的还原点；还原该备份点时**不会删除**在备份点之后新建的其他文件。

## 六、接入桌面 AI 软件当主管（MCP 配置说明）

如果你希望在 **Antigravity、CodeX、CodeBuddy 或 Claude Code** 客户端里与主管对话，由它来调用看板派工团队：

### 1. 一键写入配置
1. 在左侧栏点击 **「桌面端 MCP 接入」**。
2. 弹窗会为四个客户端依次展示四维状态：**是否检测到客户端 → 配置是否已写入 → 一键自检本机脚本状态 → 当前会话绑定与监听状态**。
3. 点击对应客户端右侧 **「一键接入」**（若暂未检测到该客户端，按钮会温和提示 **「预写入配置」**）。写入前会自动将原本配置文件另存为 `.bak-cowork` 备份，绝不破坏你的第三方 MCP 配置与 TOML 注释。
4. 点击右上角 **「一键自检」**，验证本地后台服务、MCP 工具列表与 Hook 脚本是否可正常握手响应。
5. **关键一步**：去对应桌面 AI 软件的 MCP 面板刷新列表（或重启开一个新对话），让宿主软件加载刚写入的 MCP 工具。

### 2. 四种唤醒与待命机制详解（怎么从网页喊桌面主管？）
- **1. 自动挂起监听（CodeX / Claude Code / CodeBuddy 等）**：
  - 看板顶栏默认开启 **「自动监听：开」**，MCP 工具自身已预载协约与 `cowork_standby_mode` 提示词。
  - 当支持长阻塞调用的桌面宿主调用完 `cowork_setup_board` / `cowork_dispatch_wave` 并同步结论后，主管会自动调用 `cowork_wait_board(waitForNewActivity=true)` 进入挂起等待（等待期间不再发出额外模型回合，不重复空耗主管对话额度；实际最长挂起时长受宿主单次工具超时上限限制，已为 CodeX 自动设置 `tool_timeout_sec = 3600`）。
  - 此时你在网页或手机给主管留话，通常可在 1–2 秒内中断挂起、连同项目文件变动证据一起醒来继续干活。
  - 随时点击顶栏 **「自动监听：关」**，或在对话框发送「结束监听 / 停止监听」，系统会立即释放等待中的监听。
- **2. Antigravity 右侧看板分栏直通**：
  - 在 Antigravity 内让主管唤醒或在 MCP App 中打开 **`AgentSwarm` 右侧面板**，保持「自动唤醒左侧:开」时，你在电脑网页或手机端发给主管的新消息会被自动通过官方 `app.sendMessage()` 送入 Antigravity 主对话框。
- **3. Antigravity PreInvocation Hook（按需自动带入）**：
  - 接入 Antigravity 时可勾选安装 Hook（支持随时单独点击 **「停用 Hook」** 而不影响 MCP 本身）。
  - 工作方式：仅当你在 Antigravity 里新发一条提问前，快速检查一次是否有未同步的看板 `@主管` 留言；若有，自动附加进该轮上下文；若无未读留言则秒级放行，不会改动或阻断你的输入。
- **4. 后台 CLI 兜底代答**：
  - 如果桌面客户端已关闭或暂时处于闲置未响应状态，留言下方会出现 **「本轮改由后台 CLI 主管立即代答」** 按钮（也可打开顶栏 **「CLI 代答：开」** 自动兜底），由本地已安装的命令行引擎先帮你回应或接力推进。

## 七、工作台设置：默认模型、思考强度、主题与额度

点击左侧导航 **「工作台」**：
- **为 20 款智能体设置默认模型与思考强度**：在「智能体看板」每张卡片底部直接挑选平时最顺手的默认模型与模型原生思考强度档位（例如 `low / medium / high / xhigh / max / ultra`），立即保存生效，并自动被后续新建看板、添加成员与 MCP 建板继承；也可随时点击「恢复默认」。
- **切换 4 套柔和主题**：右上角（手机端窄屏在左侧滑出抽屉内）可在 **薰衣草紫（默认）/ 雾霭蓝 / 鼠尾草绿 / 樱花粉** 之间一键切换，主界面与 Antigravity 右侧栏插件会通过 WebSocket 实时同步。
- **查看额度与切换账号**：对已安装的 Antigravity 和 CodeX 会自动读取本地会话或官方用量信息并展示剩余时间与百分比（若开启了长期后台缓存，点击卡片或顶部额度胶囊上的刷新按钮才会实时重新探测 CLI，避免后台频繁拉起命令窗口）。

## 八、用手机扫码协同与网络安全准则

1. **安全默认状态**：软件刚装好时，右上角网络状态是 **「仅本机」**。此时后台服务仅绑定在 `127.0.0.1`，同一局域网下的其他电脑和手机完全无法连接。
2. **何时以及如何开启手机访问**：
   - 点击右上角 **「仅本机」**，打开 **「允许手机 / 其他设备访问」** 开关。
   - **选对网络地址**：
     - **局域网 (`192.168.x.x` / `10.x.x.x`)**：电脑和手机连接**同一个家庭/办公室 Wi-Fi** 时优先选这个扫码（请确认路由器没有开启“AP 隔离/访客隔离”）。
     - **异地组网 (`100.x.x.x` 等)**：在外地或不同网络时使用，要求电脑和手机均已登录同一个 Tailscale 或 ZeroTier 账户。
     - `127.0.0.1` 仅限本机浏览器使用，弹窗不会再用它来生成无效的手机二维码。
   - **设备配对与撤销**：手机首次扫码带一次性配对令牌直接进入；如果手机手动输入浏览器地址访问，则必须输入弹窗展示的 **4 位数字连接码**。在弹窗中可以看到「已配对设备」清单，支持逐台点击 **「移除」** 或 **「全部撤销」**，关闭总开关后所有远程连接立即断开。
3. **重要安全禁忌**：
   - **切勿**在路由器或内网穿透工具里把 `25880` 端口直接暴露到公网互联网。
   - 在咖啡厅、机场等公共 Wi-Fi 下使用完手机访问后，请及时关闭「允许手机 / 其他设备访问」。

## 九、数据位置、多实例隔离、升级与卸载

- **数据存放路径**：
  - Windows 安装版：`%LOCALAPPDATA%\AgentSwarm\data`（内含 `cowork-board.db`、自动/手动文件备份 `snapshots\` 以及 `desktop-server.*.log`）。
  - 源码仓库运行：`项目目录\data\`。
- **如果同时运行源码版与安装版（端口占用隔离）**：
  - 安装版启动时会自动通过 `/api/health` 校验端口 `25880` 背后的数据目录身份。若发现 `25880` 已被源码旧服务或其他程序占用，安装版会自动退避到 `25881` 等空闲端口运行自己独立的数据目录，并在启动画面给出明确提示让你挑选要进入哪个实例，防止数据混用。
- **升级、备份与卸载**：
  - **升级与回退**：直接运行新版本安装程序覆盖安装，或先卸载再装新/旧版本，均**不会删除** `%LOCALAPPDATA%\AgentSwarm\data` 中的既有看板数据与历史快照；重要数据升级前可顺手把该文件夹复制一份作为冷备。
  - **彻底清除数据**：如确定再也不需要任何记录，在卸载程序后手动删除 `%LOCALAPPDATA%\AgentSwarm` 文件夹即可。

## 十、常见问题排查 (FAQ)

| 遇到问题 | 原因与解决办法 |
| :--- | :--- |
| **1. 启动提示端口被占用 / 启动失败** | 点击启动画面上的 **「重启本地服务」**；若仍异常，点击 **「查看诊断」→「复制脱敏诊断」** 检查报错详情（用户名与隐私已自动脱敏），确认防病毒软件未拦截内置的 `node.exe` |
| **2. 手机扫了二维码一直转圈打不开** | 确认电脑端弹窗内已开启「允许手机访问」；核对手机和电脑在同一 Wi-Fi 且未被路由器访客模式/AP 隔离隔断；确认 Windows 防火墙允许该程序访问「专用网络」 |
| **3. 接入 MCP 后桌面客户端看不到 `cowork_*` 工具** | 先点击弹窗里的 **「一键自检」** 确认前 3 项绿灯通过；然后在 Antigravity MCP Servers 面板点一次 **Refresh**，或关闭并新开一个 CodeX / Claude Code / CodeBuddy 对话会话 |
| **4. 发任务提示未安装或需登录** | AgentSwarm 需要调用你本机的 CLI 工具执行任务。确保对应命令在普通终端能直接运行并已完成登录（如 `codex`、`claude`、`codebuddy`、`agy`），或在右侧栏将成员切换为已安装的工具 |
| **5. 看不到想选的项目目录或被禁止选中** | 出于安全保护，不可将工作区设在磁盘根目录（`C:\`）、系统目录或软件安装目录。请点开「文档」或你的代码文件夹，或使用建板弹窗右上角的「在「文档」新建练习文件夹」 |
| **6. 如何完全退出桌面版不再后台驻留** | 关闭窗口仅最小化到系统托盘；请右键电脑右下角托盘区的 AgentSwarm 图标，点击 **「退出程序」** 即可完整结束主窗体和后台节点进程 |
